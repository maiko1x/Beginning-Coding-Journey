# Saved Prompt Patterns

A library of reusable, refined prompts. After each session, save any prompt that produced a great result here.

## Template
```
Role:        "Act as a [role]."
Context:     "I am building [what] for [who]. I'm currently [situation]."
Task:        "Help me [specific action]."
Constraints: "Keep it under [X lines]. Use only [language/library]. Avoid [anti-pattern]."
```

### General Learning
```
Act as a senior software engineer and patient teacher.
I am a beginner learning [topic]. Explain [concept] with:
1. A plain-English definition (one sentence)
2. A minimal code example
3. One common pitfall to avoid
Keep the explanation under 150 words.
```

### Code Review
```
Act as a code reviewer focused on correctness and security.
Review the following [language] code. Identify:
1. Any bugs or logic errors
2. Any security vulnerabilities
3. One specific improvement to readability or performance
Be concise — bullet points only.
```

### Debugging
```
Act as a debugging expert.
I have this error: [paste error]
Here is the relevant code: [paste code]
What is causing this error and what is the fix?
Explain the root cause in one sentence before showing the fix.
```
